# 트러블슈팅 — AI 한자 추천

| 항목 | 내용 |
| --- | --- |
| 대상 | 한자 추가 화면의 AI 추천 |
| API | `POST https://kanji-kr.onrender.com/api/suggestions` |
| 사전 | `assets/db/dictionary.db`. 한자 2,126자 (시드 899, KANJIDIC 1,227) |
| 관련 파일 | `backend/flow.py`, `lib/features/kanji_add/kanji_add_page.dart`, `lib/core/services/dictionary_db_service.dart` |

폼은 고른 카드의 `koreanMeaning`을 뜻 칸에 넣는다. 입력한 문장을 그대로 남기는 분기는 없다. 화면에 입력과 같은 뜻이 보이면, 그 문자열이 추천 결과의 뜻으로 들어온 것이다.

서버 프롬프트(`backend/flow.py`)는 Render에 배포되기 전에는 앱에 반영되지 않는다. 사전 조회와 한 글자 필터는 앱 쪽이라 핫 리스타트 후 적용된다.

## 1. 한국어 뜻이 세 카드에서 같다

| 항목 | 내용 |
| --- | --- |
| 현상 | 한자 추가에서 `높은곳`으로 추천하면 高·峰·頂의 한국어 뜻이 모두 `높을 고`이다. 음읽기·훈읽기는 글자마다 다르다 |
| 재현 | 한자 모드. 뜻 칸에 `높은곳` 입력 후 AI 추천 |
| 원인 | 프롬프트의 형식 예시가 `산 산`, `곶 갑`, `높을 고`였다. 모델이 형식이 아니라 예시 문장을 답으로 재사용했다. `높은곳`과 겹치는 예시는 `높을 고`뿐이라 세 카드에 그 한 줄을 넣었다. 응답 스키마 `koreanMeaning`은 설명 없는 문자열이라 "훈 음만"을 강제하지 않고, 서버는 모델 JSON을 사전과 대조하지 않고 그대로 반환한다 |
| 사전 값 | 高 `높을 고`, 峰 `봉우리 봉`, 頂 `정수리 정 · 꼭대기 정` |
| 조치 | 추천이 돌아온 뒤 `literal`이 같은 사전 행으로 뜻·음읽기·훈읽기·획수·JLPT를 덮는다. 예문은 모델 결과를 유지한다. 시드 행을 KANJIDIC보다 먼저 고른다. 사전에 없는 글자만 모델 뜻을 남긴다. 단어는 표제어가 사전에 있을 때만 뜻과 읽기를 덮는다 |
| 확인 | `높은곳` 추천에서 峰의 뜻이 `봉우리 봉`, 頂이 `정수리 정`이다. 세 카드가 `높을 고`로 같으면 앱이 재시작되지 않았거나 그 글자가 사전 조회에 실패한 것이다 |

## 2. 한자 추천에 단어가 섞인다

| 항목 | 내용 |
| --- | --- |
| 현상 | 한자 추가에서 `배고프다`로 추천하면 한 글자 한자와 함께 空腹, 食欲 같은 두 글자 단어가 나온다. 카드 라벨은 음읽기·훈읽기라 한자 모드가 맞다 |
| 재현 | 한자 모드. 뜻 칸에 `배고프다` 입력 후 AI 추천 |
| 원인 | 한자 프롬프트가 "한자 3개"라고만 해서, 모델이 배고픔의 일본어 단어(空腹, 食欲)를 한자 항목으로 반환했다. 두 글자는 한자 사전에 없어 1번의 사전 덮어쓰기가 적용되지 않고, 모델이 적은 뜻·읽기가 그대로 보였다 |
| 조치 | 앱은 한자 모드에서 한 글자 한자(CJK)만 남긴다. 전부 걸러지면 스낵바 `추천된 한자가 없습니다`를 보여주고 다이얼로그를 열지 않는다. `flow.py`에는 `literal`을 한 글자로 제한하고 空腹·食欲 같은 단어는 넣지 말라고 추가했다 |
| 확인 | 핫 리스타트 후 空腹, 食欲는 카드에 없다. 세 건이 모두 단어이면 스낵바가 뜬다. 한 글자 한자가 안정적으로 3장 나오려면 수정한 `flow.py`를 Render에 배포해야 한다 |

## 3. 프롬프트만 고치면 안 되는 이유

| 항목 | 내용 |
| --- | --- |
| 현상 | 예시 문장을 `高→높을 고`, `峰→봉우리 봉`, `頂→정수리 정`으로 바꾸고 "같은 뜻을 반복하지 말라"고 해도, 다른 한자의 훈음이 틀릴 수 있다 |
| 원인 | 예시는 그 세 글자에만 묶인다. 약(約)처럼 예시에 없는 한자는 모델이 훈음을 지어 낸다. 이전에 約의 뜻이 `율 율`로 나온 것과 같은 유형이다. 율은 律의 음이다 |
| 조치 | 사전에 있는 2,126자는 1번의 조회로 확정한다. 프롬프트는 사전에 없는 글자와, 어떤 한자를 고를지에만 영향을 준다 |
